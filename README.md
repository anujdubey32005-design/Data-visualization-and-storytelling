# Data-visualization-and-storytelling
Data Visualization and Storytelling using Microsoft Power BI. An interactive Superstore Sales Dashboard to analyze sales, profit, product categories, regional performance, and monthly sales trends through visual reports.


## Project Overview
This project focuses on analyzing sales data and presenting meaningful business insights through an interactive Power BI dashboard. The dashboard helps users understand sales performance, profit, regional sales, category-wise sales, and monthly sales trends.

## Objective
The main objective is to convert raw sales data into clear and meaningful visualizations that help identify business trends and support better decision-making.

## Tools and Technologies Used
- Microsoft Power BI Desktop
- CSV Dataset
- Data Visualization
- Data Analysis

## Dataset
**Dataset Name:** Sample Superstore Dataset

The dataset contains sales-related information, including:
- Order ID
- Order Date
- Customer Name
- Category
- Sub-Category
- Region
- Sales
- Profit
- Quantity
- Discount

## Dashboard Features

The Power BI dashboard includes:

1. **Total Sales:** Displays the total sales amount.
2. **Total Profit:** Displays the total profit generated.
3. **Orders:** Displays an order-related summary.
4. **Sales by Category:** Compares sales across product categories.
5. **Sales by Region:** Shows sales performance across different regions.
6. **Monthly Sales Trend:** Displays sales trends over time.

## Key Insights
- Compare sales performance across different product categories.
- Identify regions with higher sales.
- Analyze sales trends over time.
- Understand the relationship between sales and profit.

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.

4. The dashboard will open in Power BI Desktop.

## Conclusion
This project demonstrates how Power BI can be used to transform sales data into meaningful visual reports. The dashboard makes it easier to understand business performance and identify important sales trends.
